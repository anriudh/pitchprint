# Pitchprint

Pitchprint is an Android app that records one player's movement during small-sided football games, so that distance, speed, sprints and time spent in each part of the pitch can be worked out afterwards.

It is at an early stage. The current version is a raw logger: it records GNSS fixes, satellite status, raw GNSS measurements where the phone supports them, and the motion sensors, keeps recording with the screen off, and exports each session as a zip. Nothing is computed on the phone yet.

The app has no internet permission. Recordings stay on the phone until you export one yourself.

Build and install instructions will follow once the first version is usable.
